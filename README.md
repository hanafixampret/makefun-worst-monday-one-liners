One funny line, at most 140 characters, about an AI agent's worst Monday — a joke, an excuse, or a roast. The program writes the line to `/output/entry.txt`.

Entry: "My deploy failed at 9:03, my inbox hit 4,000 unread, and the stand-up that should've been an email asked me to circle back — I did. To bed."

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (139 characters, one line).
